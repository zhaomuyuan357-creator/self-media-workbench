# 小红书图文工作台 PRD

- 版本：0.5
- 状态：图文流程、ToAPIs 媒体生成与多模型文案配置已实现，待用户实机验收
- 更新日期：2026-11-09

## 1. 产品定位

为小红书创作者提供一个本地优先的内容工作台。先保存每个工作台账号的内容定位，再按定位检索热点、准备图文文案和配图，最后由操作者预览、确认并发布。此版本聚焦图文笔记；抖音成片分发、自动视频处理和视频衍生内容暂不属于内容制作主流程。

工作台包含五个独立页面：

1. **账号定位**：管理赛道、定位、受众、语气、内容结构、边界、事实规则和常用话题。
2. **内容制作**：热点扫描、文案生成与编辑、生图、选图、图文预览和发布确认。
3. **账号监测**：读取 MCP 当前登录状态和连接器能提供的账号、笔记指标。
4. **发布记录**：查看内容、来源、定位版本、任务状态和人工核验。
5. **服务设置**：设置本机小红书 MCP、多套文案模型、生图模型以及热点来源状态；文案方案可排序并按条件自动切换备用方案。

内容制作页另提供 ToAPIs 媒体生成：读取模型和参数文档，提交图片或视频异步任务，并将结果保存到本机素材库。图片可用于笔记配图；视频可预览和下载，当前没有独立的视频发布流程。

## 2. 目标用户与核心流程

### 目标用户

负责抖音或其他内容平台运营、希望把热点研究和小红书图文制作流程放在一起的个人创作者或运营者。当前系统仅支持一个工作台定位配置和一个 MCP 当前登录会话。

### 核心流程

1. 在“账号定位”填写必需字段并保存。必需字段为账号名称、内容赛道、定位、目标受众和表达语气。
2. 进入“内容制作”，按账号赛道或自定义主题扫描 AIHOT 和所选 Agent-Reach 来源。
3. 浏览来源、摘要、时间和链接，选择要参考的热点；也可以不选热点，手动填写选题。
4. 按需调用文案模型生成标题、正文和话题。用户编辑并核对来源和事实。
5. 描述配图并按需调用生图模型；生成图片保存在本机，用户选择要放进笔记的图片。
6. 检查图文预览、实际登录账号和素材权利，再明确确认发布。
7. 在“发布记录”查看 MCP 返回状态；结果不明确时先去小红书核验，不自动重发。
8. 在独立的“账号监测”页读取登录状态和当前可读指标。

热点检索、文案生成、生图、发布是分开的步骤，不会因扫描热点而自动生成图片或发布内容。

## 3. 账号定位

定位记录按版本保存，每个发布任务绑定创建时的定位版本。当前只支持一个定位配置；它与真实小红书账号身份分开管理。操作者在发布前核对 MCP 当前登录账号，工作台不会基于昵称自动推断定位绑定关系。

字段包括账号名称、内容赛道、定位说明、受众、语气、常用结构、内容边界、事实规则和常用话题。登录凭据不属于定位，也不会写进提示词或工作台数据库。

## 4. 功能范围与边界

| 模块 | 已实现 | 限制 |
| --- | --- | --- |
| 账号定位 | 单账号配置、必填校验、版本快照 | 多账号隔离和平台身份自动绑定 |
| 热点扫描 | AIHOT 的 hot/latest/search；Agent-Reach 网页、GitHub、YouTube、B站、V2EX 默认渠道；Reddit/X `public-web` 可选 | 用户主动触发；非持续采集，不覆盖全网；无全量去重、趋势评分或提醒 |
| 文案生成 | 最多配置 8 套 OpenAI 兼容 Chat Completions 或 Responses 方案；支持 DeepSeek、通义千问、OpenAI、AixHan 和自定义地址；用户排序首选与备用方案；按定位、选题、补充说明和勾选来源生成不超过 20 字标题、不超过 1000 字正文和最多 10 个话题；可编辑 | 用户提供各方案的准确模型 ID 和 API Key；自动切换仅对 HTTP 429 限流生效；其他服务错误、连接中断、超时、响应格式异常不自动重试；不保证事实准确或“没有 AI 味”，不自动核实来源、不生成或发布视频 |
| 配图生成 | OpenAI 兼容 `images/generations`，或 ToAPIs 图片模型；支持 PNG、JPEG、WebP；单图不超过 25 MB；最多选 9 张 | 需用户提供可用模型服务并承担费用；无模板排版、文字排版或人工修图 |
| 图文发布 | 模拟模式；本机 MCP `publish_content` 图文提交；标题、正文、图片路径和话题参数；明确确认、状态记录和人工核验 | 无后台无人值守发布或批量排期；MCP 返回不代表审核通过或公开可见 |
| ToAPIs 视频生成 | 读取模型文档、提交异步任务、查询状态；结果下载并保存为 MP4、MOV 或 WebM（最大 1 GB），可预览和下载 | 需用户提供 ToAPIs API Key 并承担模型费用；当前没有独立视频发布、剪辑或改编流程 |
| 历史视频 | 旧数据库视频记录、视频素材和显式视频发布分支继续兼容 | 视频发布仍需人工核对并通过已有显式发布入口操作 |
| 账号监测 | MCP 当前登录状态、资料、可读粉丝/关注/获赞与收藏、已加载笔记及互动数据快照 | 当前不提供播放量；返回笔记不保证覆盖全部历史内容 |
| 设置与密钥 | MCP 本机地址限制；文案、生图、ToAPIs 分别配置；文案可有序配置多套服务商方案；密钥仅在当前进程内存；ToAPIs 国际站/中国站可选 | 重启需重新输入密钥；不在数据库保存 API Key |

### 热点来源状态

- AIHOT 只通过 HTTPS 向 `aihot.news` 发 GET，读取热点榜、近期内容和主题搜索结果。返回资料按不可信第三方内容处理。
- Agent-Reach 作为只读来源调用。已安装或未验证的默认渠道会在扫描中逐一显示成功或错误；Reddit 与 X 只请求 `public-web`。X 当前测试未取得可用搜索内容时显示来源错误，不据此推断需要登录。
- 结果的时间和排名取决于来源接口和搜索索引。手动扫描的结果不是实时全量榜单。
- AIHOT 条款允许个人非商业、公益非商业及组织内部使用；面向外部的商业用途须事先获得书面授权：<https://aihot.news/terms>。这项边界适用于 AIHOT 服务数据和内容，不因 Skill 文件的许可证改变。

### 文案模型方案

- 最多保存 8 套服务商方案，按列表顺序尝试；首位为首选，后续为备用。DeepSeek、通义千问、OpenAI、AixHan 提供快捷地址，其他 OpenAI 兼容服务可使用自定义地址和协议。
- 每套方案独立配置模型 ID 和 API Key。Key 只保存在当前进程内存；SQLite 只保存非敏感的方案名称、服务商、地址、协议、模型 ID 和顺序。服务重启后需要重新输入 Key。
- 开启自动切换时，首选方案仅在 HTTP 429 限流后尝试后续已连接方案。其他服务错误、连接断开、超时和响应解析失败不重发，因为无法判断上一次请求是否已完成或计费。手动测试只请求选中的方案。
- 模型调用按各服务商自己的计费规则收费。首选顺序由用户设置；工作台不自动判断模型价格或保证备用服务的额度、兼容性与可用性。

## 5. 发布和核验

图文 MCP 工具参数为 `publish_content(title, content, images, tags)`。发布任务创建后，操作者可在确认框核对工作台账号名称、实际登录身份、图片数和标题。

- `simulated`：仅本地模拟，没有上传。
- `submitting`：连接器正在处理。
- `submitted`：连接器返回提交说明；不表示审核通过或公开可见。
- `under_review`：平台显示审核中或操作者登记为审核中。
- `verified_visible`：操作者在小红书确认公开可见。
- `failed`：连接器明确失败或操作者核实没有提交成功。
- `unknown_manual_check`：超时、连接器异常或返回内容不足，结果不明确。

`unknown_manual_check` 必须先人工核验，不自动再次提交。内容指纹用于降低重复提交风险。模拟发布不会进入真实平台核验流程。

## 6. 非目标

- 不承诺监控全网、所有平台的实时热点或平台完整历史内容。
- 不提供定时采集、趋势评分、通知、自动选题、无人值守发帖或批量轮发。
- 不做视频剪辑、转码、转写、画面理解或自动从视频改写图文。
- 不做小红书点赞、评论、私信等互动，也不绕过登录校验、验证码或风控。
- 不将 MCP 的提交响应当作平台审核结果或笔记公开状态。

## 7. 技术结构

- `app.py`：本机 HTTP API 与工作流协调，监听 `127.0.0.1`。
- `workbench/store.py`：SQLite 账号定位、媒体素材、内容包、发布任务和监测快照；多图通过 `asset_ids_json` 保存。
- `workbench/trends.py`：AIHOT 和 Agent-Reach 只读热点适配器。
- `workbench/generators.py`：文案模型适配器。
- `workbench/images.py`：生图模型适配器。
- `workbench/publishers.py`：模拟发布器和小红书 MCP 发布/读取适配器。
- `web/`：账号定位、图文制作、监测、记录、设置五个页面。

系统为模块化单体。热点来源、生成模型、媒体存储和发布器通过边界清楚的模块接入；增加来源时不需要修改内容包或发布状态模型。

## 8. 验收标准

- 未保存必需定位字段时，内容制作保持锁定；保存后可以进入内容制作。
- 热点扫描先显示各来源状态和结果；勾选的来源才传给生成器。
- 可添加、测试、排序和删除文案模型方案；切换首选顺序后生成请求使用新的列表顺序，敏感 Key 不会出现在 API 响应或 SQLite 中。
- 自动切换只对 HTTP 429 限流生效；其他服务错误、连接中断、超时或无法解析响应时只返回错误，不发起第二次生成请求。
- 文案可手工编辑；生图必须由操作者主动触发；图片可选择、移除并在图文预览中显示。
- ToAPIs 设置页可保存站点和 API Key 状态；密钥不出现在接口响应、日志或 SQLite 中。
- ToAPIs 生成前读取当前 Key 的模型列表与所选模型参数说明；图片和视频任务状态可恢复查询，结果保存到本机素材库。
- 请求结果不明确时沿用同一任务编号查询，不自动创建新任务；媒体下载失败时只允许重试下载，不重复提交计费生成。
- ToAPIs 媒体下载只允许 HTTPS 公网主机，固定到已校验的公网 IP，并限制重定向目标和文件大小。
- 图文发布任务保存多张图片、内容类型、定位版本和研究来源。
- 模拟发布全程不访问小红书发布工具；真实发布前显示明确确认。
- 历史视频任务仍可读取，显式视频内容类型仍可走旧发布分支。
- 文案/生图重定向不会把 API Key 转发到其他地址；MCP 地址仅允许本机。
- 未知发布结果提示人工核验，且重复提交保护仍工作。
- 完整测试通过；不向真实账号发布测试内容。
